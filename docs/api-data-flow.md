# 계산 결과와 참고 자료의 조회

2026-10-25. `useBacktest`는 다음 두 요청의 수명을 관리한다.

1. `POST /api/v1/backtest`: 다섯 `include_*`를 false로 보내 계산 결과를 먼저 표시한다.
2. `GET /api/v1/market-data`: 성공 결과의 주식 심볼·제출 기간으로 참고 자료를 조회한다.

참고 자료를 기다리는 동안에도 계산 결과와 입력 폼은 사용할 수 있다. 참고 자료의
HTTP 오류나 섹션별 timeout/error가 있으면 조회만 재시도하며 계산을 반복하지 않는다.
GET은 최대 27초, 계산 POST는 기존 185초 클라이언트 제한을 사용한다.

계산·조회를 이어서 관리하는 AbortController는 각 요청에 명시적으로 전달한다.
공유 axios 클라이언트에 전역 취소 signal을 등록하지 않는다. 새 실행 또는 화면 이탈은
이전 요청을 취소하며 이전 응답은 현재 결과에 반영하지 않는다.

참고 응답은 정해진 참고 자료 필드만 병합한다. 투자금·최종 평가금·거래·자산 곡선은
계산 응답을 유지한다. S&P 500의 기간 수익률이 정상 숫자일 때만 비교 수익률을 표시한다.
포트폴리오 API 타입은 화면의 `PortfolioData`와 같은 정의를 사용한다.

새 조회 API를 제공하는 백엔드를 먼저 배포한다. 개발 Vite 및 운영 Nginx는
`/api/v1/` 전체를 백엔드로 전달해야 한다. 기존 POST 경로·결과 형식은 유지된다.
서버의 입력·슬롯·시간 한도는 [백엔드 API 문서](https://github.com/kyj0503/backtest/blob/main/docs/architecture/api-boundaries.md)를 참조한다.

2026-10-25 검증: Docker 테스트 348개, ESLint·두 TypeScript 검사와 의존성 감사를
통과했다. 배포용 FE·BE 이미지와 격리 MySQL을 실행한 브라우저 검증에서 참고 GET의
503 오류 중 계산 결과를 보존하고, 복구 후 계산 POST를 추가하지 않고 참고 차트를
채웠다. 시세는 합성 데이터이며 운영 자격증명은 사용하지 않았다.
